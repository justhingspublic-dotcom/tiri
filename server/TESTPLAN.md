# TIRI 表單後端 — 驗收測試計畫（PO 手動測試用）

> 用法：照順序做，每項「操作 → 預期結果」，符合就打勾。
> 任何一項不符 → 記下「哪一項＋實際看到什麼」，不用當場修。
> 預估時間：完整跑一輪約 60–90 分鐘。

## 1. 前台六個表單逐一送出（original 版）

每個表單都做同一套動作（以第一個為例，其餘依表格換網址）：

**操作模板：**
1. 開該表單頁 → 每個欄位都填，測試值帶表單代號和日期方便對帳（例：姓名填「測試join-0728」）
2. 按送出

**每個表單的預期結果（四個都要對）：**
- 前台：表單消失，上方出現綠色訊息「**已收到您的填寫，我們會盡快與您聯繫，謝謝!**」

- Gmail：收到通知信，開頭文字在最上方，接著表單名、時間、頁面網址，**填寫內容以表格呈現**（欄位名稱在左、灰底；填的值在右）
- 信裡的欄位值 = 你剛剛填的（抽對兩三個欄位即可）

## 2. 後台功能

### 2.1 登入 / 登出
- [ ] 開 http://localhost:8000/admin/logout 不會直接開（是按鈕才有作用）；先確定目前是登出狀態：直接開 http://localhost:8000/admin/inbox → 被導回登入頁
- [ ] 登入頁輸入正確帳號＋**錯的密碼** → 紅色「帳號或密碼錯誤」，留在登入頁
- [ ] 按「快速登入（office@tiri.tw）」→ 直接進儀表板
- [ ] 右上角選單按登出 → 回到登入頁；按瀏覽器「上一頁」再開 /admin → 仍要求登入（不會看到殘留資料）

### 2.2 儀表板數字
> 資料庫已在 7/27 清空，以下數字應該剛好對得上（假設第 1 節送了 7 筆、都成功）。

- [ ] 「總收件」數字 = 收件匣「全部」的數字 = 7
- [ ] 「今日」= 7、「近 7 日」= 7
- [ ] 「寄信失敗」= 0
- [ ] 各表單統計：六個表單都有一列（加入會員 2 筆、其他各 1），百分比加總約 100%
- [ ] 「最近收件」列表最上面 = 你最後送出的那筆

### 2.3 收件匣：篩選與匯出 CSV
- [ ] 上方分類列有「全部＋六個表單」，每個都帶數字，數字加總 = 全部
- [ ] 點「聯絡我們」→ 列表只剩聯絡我們的資料，切換有滑動效果、頁面不重新載入
- [ ] 停在「聯絡我們」按「匯出 CSV」→ 下載 contact-submissions.csv，只含聯絡我們的資料
- [ ] 切回「全部」按「匯出 CSV」→ 下載 all-submissions.csv
- [ ] 用 Excel 或 Numbers 開匯出檔 → **中文不是亂碼**；欄位順序：編號、時間、表單、各欄位、通知信；不同表單的欄位各自成欄、沒填的留白

### 2.4 郵件設定（每張卡獨立儲存、儲存不重整）
- [ ] SMTP 卡與文案卡右下角有自己的「儲存設定」，只有**該卡**有改動時才可按（改 A 卡不會點亮 B 卡的按鈕）
- [ ] 通知信卡：收件人的「儲存」是**實心紫色小鈕、嵌在輸入框最右側**，改了收件人才可按，按下只存收件人
- [ ] 通知信卡：「測試模式」勾勾**點了立即套用**（跳提示「測試模式已開啟/關閉」），不用按任何儲存；儀表板的測試模式卡同步變化
- [ ] 任何儲存動作 → **頁面不重整**、右下角跳綠色提示、停留在原本的分頁與位置
- [ ] 「通知信文案」分頁選「董監事課程」→ 主旨改成「（測試）董監事課程有新報名」、開頭文字填一句話 → 儲存
  → **仍停留在董監事課程的編輯畫面**（2.4 修復驗證點）→ 前台重送一次 trainbod.html → 信件主旨、開頭 = 新文案
- [ ] 把剛剛的主旨、開頭清空 → 儲存 → 再送一次 → 信件回到預設主旨「[TIRI 網站] 董監事課程 — 新的表單填寫」
- [ ] SMTP 密碼欄**留空**直接按儲存 → 再寄一次測試信仍成功（留空＝不變更，不會把密碼洗掉）
- [ ] 「寄一封測試信」在通知信卡右下角 → 按下後不重整，成功時跳綠色「測試信已寄出！」（會先套用本頁目前填的內容再寄）

### 2.5 帳號設定（兩卡分離、即時驗證不重整）
- [ ] 基本資料卡：改暱稱 → 右下角「儲存變更」變可按 → 按下 → **不重整**、跳綠色提示、**右上角暱稱立刻變**；改回原本的
- [ ] 變更密碼卡：「變更」按鈕在卡片右下角，兩欄都沒填時不可按
- [ ] 新密碼填 7 個字元 → **邊打就出現**紅字「新密碼至少 8 個字元」、「變更」不可按（不用按送出）
- [ ] 兩次密碼填不一樣 → 紅字「兩次輸入的新密碼不一致」、「變更」不可按
- [ ] 改成一致且滿 8 字 → 紅字消失、「變更」可按 → 按下 → **不重整**、跳綠色「密碼已更新」、兩欄清空
  → 登出 → 舊密碼登入失敗、新密碼成功
  ⚠️ 測完把密碼改回原本的，或把新密碼記在安全的地方

### 2.6 深淺色模式
- [ ] 右上角切深色 → 整個後台變深色、左上 logo 變白色、選中項目是暗梅色
- [ ] 深色狀態下重新整理 → 仍是深色（有記住）
- [ ] 逛一圈儀表板/收件匣/設定頁 → 沒有刺眼的白色區塊或看不清的文字 → 切回淺色

## 3. 邊界情境

- [ ] **必填未填**：任一表單什麼都不填直接按送出 →
  表單上方紅色訊息「請填寫必填欄位：（欄位名列表）」、表單還在、後台**沒有**新增資料、**沒有**收到信
- [ ] **只填部分必填**：填一半送出 → 紅色訊息只列出還沒填的必填欄位
- [ ] **表單亂填**：欄位塞 emoji 😀、英文、引號 "quote"、一段 500 字長文 → 送出成功；
  收件匣展開顯示正常、通知信內容正常、匯出 CSV 用 Excel 開不會亂掉
- [ ] **後端沒開**：把後端終端機 Ctrl+C 停掉 → 前台送出表單 →
  紅色「送出失敗，請稍後再試，或直接來信 office@tiri.tw」、送出按鈕恢復可按 →
  重啟後端、同一頁再按一次送出 → 成功
- [ ] **手機開前台表單**：
  1. Mac 查 IP：終端機 `ipconfig getifaddr en0`（得到類似 192.168.x.x）
  2. ⚠️ forms.js 預設打 localhost，手機上會失敗。暫時把
     [original/js/forms.js](../original/js/forms.js) 第 3 行的 `http://localhost:8000`
     改成 `http://192.168.x.x:8000`（**測完改回來**）；或這項留到部署完用正式網址測
  3. 手機連同一個 Wi-Fi，開 http://192.168.x.x:8080/original/html/contact.html
  → 表單在手機上排版正常、能捲動填寫、送出後綠色訊息看得到、後台多一筆
- [ ] **手機開後台**（選測）：手機開 http://192.168.x.x:8000/admin → 登入後版面可用
