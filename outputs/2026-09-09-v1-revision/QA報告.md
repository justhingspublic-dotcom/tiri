## 保留的限制與缺件

- 05-B：正式合作夥伴 Logo。
- 08-D：余宛如、呂政達、呂軍甫、徐美華、烏恩婷、藍世旻、邱榮振，7 位缺照片。表格與文字可先驗收；沒有用其他人照片替代。
- 17、20、23、25、41：活動花絮版型參考，以及四處指定 Banner 資料。
- 32-B：尚未提供的正式／歷屆獎項資料。2025 是得獎；2026 是入選。
- 4 個 2019 Accupass 頁無原始 Banner；其餘非 Accupass 的歷史文章不是報名頁，保留文章入口。
- A03–A09 的保存檔為 960px，用於實際卡片／側圖；沒有取回平台列示的最高解析度，不能作為大幅印刷原稿。A01、A02 的保存來源為 2560px；新全寬 Banner 使用 1920px 網站檔。
- 商周官網與原優惠深連結目前導向商周官方系統中斷公告；屬外部站點狀態。
- 全倉庫 `npm run check` 的 29 個警告均在未修改的 `server/templates`／`server/static`，是靜態工具無法解析的伺服器路徑／既有字型引用。v1 範圍檢查為 0 缺檔。
- 另有一個原文章 `20240409-8922-8927.html` 的既有 `#_ftn1` 註腳沒有對應節點；本輪沒有改寫該文章內容或杜撰註腳。

## 重跑檢查

在 `WEB DEMO` 執行：

```sh
.venv/bin/python outputs/2026-09-09-v1-revision/validate_revision.py
node --check v1/js/main.js
node --check v1/js/navbar.js
.venv/bin/python _archive/scripts/v1build/build_search_index.py
```

素材與來源的 HTML 快照存成 `.html.txt`，避免被誤當網站頁面掃描。原始會議紀錄及參考分析仍完整保留。
